# Programming-Assignment-1

### Experiment 1 is all about creating simple Python functions using string operations, slicing, string methods, and sequence unpacking.

## How It's Made
### This programming assignment was made in the Jupyter notebook and Python. 

### In Problem 1, the program defines a function called `rotate_word()` that moves the first character of a word to the end while keeping the other characters in the same order.

### In Problem 2, the program defines a function called `make_username()` that creates a username using the user's first name and last name. 

### In Problem 3, the program defines a function called `swap_bookends()` that swaps the first and last elements of a list while keeping the middle elements in the same order.
